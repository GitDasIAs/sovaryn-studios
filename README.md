# Sovaryn Studios

Official website of Sovaryn Studios, an independent studio building games and tools.

Static site (HTML and CSS, no build step). The repository root is the site root.

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000.

## Deploy

Import this repository on Vercel with the default settings. No build command and no output directory are needed.

## Status

Early version. Pages for projects, downloads and documentation will fill in as real releases exist.
